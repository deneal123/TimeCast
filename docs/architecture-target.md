# Целевая архитектура

Документ фиксирует направление («вектор») развития TimeCast. Текущее состояние
описано в [backend.md](backend.md) и [frontend.md](frontend.md); здесь — куда идём.

## Северная звезда

Переиспользуемая **Python-библиотека** для обучения и инференса моделей прогнозирования
временных рядов — ядро и продукт. Поверх неё:
- тонкий **FastAPI**-слой (HTTP/SSE),
- **React + Plotly** дашборд для визуализации обучения и инференса.

БД в продукте не нужна — вырезана.

## Схема

```text
┌────────────────────────────────────────────────────────┐
│  timecast/  (pip-пакет, чистый Python API)               │  ← ЯДРО
│                                                          │
│  data/       загрузка/склейка CSV (DuckDB), датасеты      │
│  models/     classic (sktime) + neiro (iTransformer)      │
│  training/   обучение, выбор лучшей модели, чекпойнты      │
│  inference/  прогноз, загрузка весов (HuggingFace)        │
│  season/     сезонная декомпозиция (statsmodels)          │
│                                                          │
│  НЕ зависит от: FastAPI, env, фиксированных путей          │
└────────────────────────────────────────────────────────┘
        ▲ import                         ▲ import
        │                                │
┌───────────────────┐           ┌──────────────────────┐
│ FastAPI (API)      │           │ ноутбуки / скрипты /  │
│ тонкий слой:       │           │ другие сервисы        │
│  request → call →  │           └──────────────────────┘
│  result / SSE      │
└───────────────────┘
        ▲ HTTP / SSE
        │
┌──────────────────────────────────┐
│ React-дашборд (Plotly)            │
│  • прогноз vs факт по item_id     │
│  • метрики/лосс обучения (live)   │
│  • сезонная декомпозиция          │
└──────────────────────────────────┘
```

## Принципы

1. **Библиотека не знает про HTTP.** Внутри — доменные исключения
   (`TimeCastError`, `DataNotFoundError`, `ValidationFailedError`), а не
   `fastapi.HTTPException`. Перевод в HTTP-коды — единым обработчиком на уровне FastAPI.
2. **Никакого скрытого состояния.** Пути к данным/весам/графикам и гиперпараметры
   передаются явно (dataclass-конфиг операции), а не читаются из `env` внутри пайплайнов.
3. **Явный публичный API.** `from timecast import train_classic, infer_neiro, ...` —
   высокоуровневые функции с типизированными аргументами и результатом.
4. **Синхронное ядро.** Обучение — CPU/GPU-bound; «фейковый» `async` убирается.
   Асинхронность живёт на уровне FastAPI (`run_in_executor`).
5. **Структурированный результат для дашборда.** Эндпоинты возвращают данные для
   графиков (прогноз, факт, метрики, пути к артефактам), а не только zip.

## Целевой публичный API (эскиз)

```python
from timecast import (
    load_dataset,        # CSV → датасет по store/item
    train_classic,       # sktime: AutoARIMA/ETS/Prophet/TBATS
    train_neiro,         # iTransformer
    infer_classic,
    infer_neiro,
    season_analytic,     # декомпозиция тренд/сезон/остаток
)

ds = load_dataset(sales_csv, dates_csv, prices_csv, store_id="STORE_1")
result = train_classic(ds, seasonal={"week": 7, "month": 30}, save_dir="weights/")
forecast = infer_classic(ds, weights_dir="weights/", horizon=28)
```

> Эскиз ориентировочный — финальные сигнатуры уточняются на Этапе B (см. [../TODO.md](../TODO.md)).
